# 03 — Перевести внутренние контексты на живые ссылки карт

**Что сделать:** перевести все зарегистрированные контексты, которым карта уже известна, на объект текущей ветки. Stable ID остаётся формой сериализации, но больше не служит единственным runtime-путём обратно к карте.

**Блокируется:** 02 — «Ввести глубокий PhysicalCardLedger».

**Статус:** черновик — ожидает утверждения перед публикацией в GitHub.

## Критерии приёмки

- [ ] `TemporaryCardControl` хранит объект карты без дублирующего ID; ID получается из объекта на границе сериализации и сравнения.
- [ ] `EffectSourceContext` различает физический источник с картой и синтетический источник без карты; фиктивные ссылки не создаются.
- [ ] Все другие контексты с уже известной картой закрыты в реестре и больше не восстанавливают объект по ID.
- [ ] Fork перепривязывает долгоживущие ссылки через Ledger к объектам child; уничтожение, снятие контроля, временное извлечение и rollback не оставляют наблюдаемых висячих ссылок.
- [ ] Fingerprints, recurrence keys, события и snapshots явно проецируют только stable ID и логические поля, не сериализуя объект карты.
- [ ] Тяжёлый прогон устраняет категории `temporaryControl` и `effectSource`: `1 205 146` из исходных `1 214 045` точечных поисков.
