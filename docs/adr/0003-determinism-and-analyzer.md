# ADR-0003: Воспроизводимость и граница Analyzer

## Контекст

Симулятор должен воспроизводить один и тот же запуск с заданным seed, а анализатор текущего хода должен исследовать варианты, не превращаясь в стратегию игрока. Для этого нужны разные права на RNG, состояние и информацию.

## Решение

Игровой движок использует RNG с заданным seed. `fork()` создаёт независимую ветку с текущей позицией исходного RNG и не продвигает исходную игру. Когда правило оставляет выбор без стратегического решения, baseline выбирает первый разрешённый вариант в стабильном порядке движка.

`Strategy` принимает решения только за игрока на основе разрешённых действий и доступной ему информации. `Best-Move Analyzer` остаётся отдельным компонентом анализа: он может получить полное состояние, включая скрытую информацию, создать ветку RNG из текущей позиции исходного потока с сохранением метаданных seed, перечислить разрешённые линии текущего хода и применить критерий, переданный вызывающим кодом. Analyzer не меняет разрешение эффектов, `listLegalActions` или универсальное понятие лучшего хода.

## Альтернативы

- Поместить Analyzer внутрь `BotStrategy` и дать ему те же права, что игроку. Действующий код и документация разделяют эти поверхности; исходные мотивы выбора неизвестны.
- Использовать случайный запасной вариант для невыбранного разрешённого выбора. Текущий стабильный порядок и тесты подтверждают другой контракт; историческая дата решения неизвестна.
- Разрешить Analyzer продвигать общий RNG или изменять разрешение эффектов при переборе. Текущая граница `fork()` и анализа исключает это; неизвестно, обсуждался ли вариант первоначально.

## Причины выбора

RNG с заданным seed делает результаты проверяемыми, а `fork()` позволяет исследовать альтернативы без побочных эффектов для исходной партии. Отдельная граница Analyzer не смешивает анализ скрытого состояния с моделью реального игрока и не заставляет движок выбирать критерий «лучшего» хода.

## Последствия

### Положительные

- Одинаковые seed и входы дают воспроизводимые последовательности, тесты и отчёты симуляции.
- Analyzer может перебирать варианты, не загрязняя исходное состояние и RNG.
- Стратегии остаются моделями разрешённых решений игрока без доступа к будущему RNG и скрытому состоянию противника.

### Отрицательные

- Новые случайные операции должны проходить через RNG с заданным seed и учитывать семантику `fork()`.
- Сравнение Analyzer требует явно переданного критерия оценки.
- Полная многотуровая аналитика не появляется автоматически из текущей границы одного хода.
