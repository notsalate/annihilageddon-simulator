# PR #137: задачи #152–#176 — исторический дизайн

## Цель

Документирует принятые архитектурные решения задач #152–#176. Он не фиксирует
их завершение и не заменяет финальную сверку требований на точном CODE SHA.

## Архитектура

1. Defense получает канонический snapshot до передачи choices стратегии;
   mutable поля стратегии не участвуют в исполнении и журналировании.
2. Effect Runtime Catalog владеет decode, source kind и policy. Raw effects
   декодируются до проверки timing и applicability.
3. Attack replacement и `afterDamageDealt` используют типизированные
   Catalog/dispatch boundaries, чтобы ошибка и terminal result не терялись.
4. Control Ledger задаёт physical card zones через descriptors для cloning,
   inventory guards и scoring traversal.
5. Guards decoder/Catalog анализируют статические TypeScript export/import
   цепочки и разрешают только явно названные trusted adapters. Произвольный
   JavaScript value flow остаётся вне модели угроз.
