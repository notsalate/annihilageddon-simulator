# PR #137 issues #152–#176 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть незавершённые критерии задач #152–#176 в PR #137 и привязать их к закрытию issues при merge.

**Architecture:** Defense, Catalog, attack/trigger flows и Control Ledger меняются через их существующие публичные границы. Каждый issue остаётся отдельным TDD-коммитом; завершающие test и documentation задачи выполняются после изменения владельцев поведения.

**Tech Stack:** TypeScript, Node.js built-in test runner, ESLint, строгий TypeScript, GitHub PR #137.

## Global Constraints

- Не менять package metadata, lockfile, зависимости, CI/CD и `data/import/**`.
- Каждый issue выполняет один `coder` в отдельном worktree, созданном от текущего интеграционного head.
- Сначала тест с ожидаемым RED, затем минимальная реализация, затем GREEN и точечная suite.
- Сохранять deterministic seeded RNG, stable IDs и draft-статус PR.
- Перед интеграцией проверять diff, TDD-вывод и затронутые AGENTS.md; после всех задач выполнить полный gate.
