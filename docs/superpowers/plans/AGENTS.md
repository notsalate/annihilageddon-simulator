# AGENTS.md

## Purpose

This folder owns executable implementation plans for multi-step changes.

## Ownership

- Markdown task plans in this folder.

## Local Contracts

- Each task names its owned files, required tests, and verification command.
- Plans must distinguish existing work from work still required.

## Work Guidance

- Keep tasks independently reviewable and ordered by their technical dependencies.

## Verification

- Run `git diff --check` for plan changes.
